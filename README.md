# Neiroad: распознавание объектов для проекта автобусных остановок

Учебный проект компьютерного зрения: дообученная модель YOLO11s для распознавания объектов на кадрах. Архив содержит веса модели, параметры запуска обучения и сохранённые метрики.

## Что включено

- `weights/best.pt` — итоговые веса (19 МБ).
- `metrics/args.yaml` — параметры обучения: 60 эпох, размер изображения 480, исходная модель `yolo11s.pt`.
- `metrics/results.csv` и графики — метрики и матрицы ошибок из сохранённого запуска.

Модель обучалась на трёх классах: `bus_sign`, `bus_station`, `cheloveki`.

## Результат последней эпохи

По сохранённому `results.csv` на валидационном наборе последняя эпоха показывает precision 0.9535, recall 0.9303, mAP@0.5 0.9545 и mAP@0.5:0.95 0.8440. Это метрики одного сохранённого запуска, а не независимая оценка обобщающей способности модели.

## Ограничения содержимого

В архиве не найден код интеграции с Raspberry Pi, автобусным видеопотоком, расписанием или оповещениями водителя. Сохранённый `yolo_detect.py` почти совпадает с [публичным GitHub Gist](https://gist.github.com/abec09/89941f4e151aca0a07c71dc73cec5559), где лицензия не указана, поэтому он сюда не включён. Видеоданные и изображения кадров также не включены: они содержат людей и не нужны для публикации весов и метрик.

Таким образом, этот репозиторий публикует артефакты обучения модели, а не готовую систему контроля автобусных остановок.
